# نظام إدارة العملاء والمواعيد — Frontend Only

تطبيق React كامل يعمل بالكامل داخل المتصفح، **بدون أي Backend أو Server أو قاعدة بيانات خارجية**. كل البيانات تُخزَّن في `localStorage` الخاص بالمتصفح، والنسخ الاحتياطي/الاستعادة تتم عبر ملفات Excel.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:5173`. لا حاجة لأي إعداد سيرفر أو قاعدة بيانات — التطبيق يعمل فورًا.

## البناء للنشر (Static Hosting)

```bash
npm run build
```

الناتج في `dist/` هو ملفات ثابتة بالكامل (HTML/CSS/JS) — ارفعها إلى أي استضافة ثابتة (Netlify, Vercel, GitHub Pages, أو حتى فتح `dist/index.html` مباشرة من الجهاز). لا يوجد أي استدعاء API أو اتصال بالإنترنت مطلوب بعد التحميل الأول (باستثناء تحميل خط Google Fonts في `index.html`، يمكن حذفه إن أردت عملاً Offline بنسبة 100%).

## البنية

```
src/
  types/index.ts          تعريفات TypeScript للبيانات (Customer, Appointment, ...)
  data/
    storage.ts             طبقة LocalStorage العامة (get/set/init/clearAll)
    customersStorage.ts     العملاء + أنواع العملاء + الملاحظات
    appointmentsStorage.ts  المواعيد + التذكيرات
    notificationsStorage.ts الإشعارات
  utils/
    excel.ts                تصدير/استيراد Excel (عملاء، مواعيد، نسخة احتياطية كاملة)
    id.ts                   توليد معرّفات فريدة
  hooks/
    useReminderChecker.ts   فحص دوري (setInterval) لإرسال التذكيرات + Notification API
  components/                Modal, Layout, النماذج المختلفة (كلها Modals/Drawers)
  pages/
    CustomersPage.tsx        صفحة العملاء
    AppointmentsPage.tsx     صفحة المواعيد
```

لا تتعامل أي Component مع `localStorage.getItem/setItem` مباشرة — كل شيء يمر عبر `src/data/*`.

## كيف تعمل التذكيرات (Frontend Only)

- عند إنشاء/تعديل أي موعد، يتم توليد سجلّي تذكير (`24h` و`1h` قبل الموعد) في `localStorage.reminders`.
- خطاف `useReminderChecker` يشغّل `setInterval` كل 30 ثانية يفحص التذكيرات المستحقة، وينشئ إشعارًا داخليًا + إشعار متصفح حقيقي (Notification API) إن مُنح الإذن.
- **مهم**: هذا يعمل فقط أثناء فتح صفحة الموقع في المتصفح (لا يوجد Server يعمل في الخلفية). إذا أغلقت التبويب، لن تُرسَل تذكيرات حتى تفتح الموقع من جديد — عندها سيتم فحص أي تذكيرات فات موعدها وإرسالها فورًا.
- لا يتكرر إرسال نفس التذكير (`sent: true` بعد الإرسال)، ولا يُرسَل تذكير لموعد ملغي أو مكتمل.

## Excel — التصدير والاستيراد (حقيقي وليس شكليًا)

- **تصدير/استيراد العملاء والمواعيد**: من كل صفحة، بنفس الأعمدة المطلوبة تمامًا.
- **نسخة احتياطية كاملة** (من الإعدادات في الشريط الجانبي): ملف Excel واحد متعدد الصفحات (`Customers`, `CustomerTypes`, `Appointments`, `Notes`) باسم `CRM_Backup_YYYY-MM-DD.xlsx`.
- عند الاستيراد: معاينة كاملة لكل صف مع الأخطاء، فحص تكرار (رقم الهاتف للعملاء، العميل+التاريخ+الوقت للمواعيد)، ثم تأكيد الاستيراد.
- عند استعادة نسخة احتياطية كاملة: يمكنك الاختيار بين **الدمج** (Merge — لا يكرر بيانات موجودة) أو **الاستبدال الكامل** (Replace).

## مسح جميع البيانات

من الإعدادات → "مسح جميع البيانات": يطلب كتابة `DELETE` قبل الحذف النهائي، تحذيرًا من فقدان لا رجعة فيه.

## ملاحظة مهمة

بما أن البيانات محفوظة فقط في `localStorage` لهذا المتصفح/الجهاز، فإن مسح بيانات الموقع (Clear Site Data)، أو استخدام وضع التصفح الخاص، أو تغيير المتصفح/الجهاز، سيؤدي لعدم رؤية البيانات (أو فقدانها إن مُسحت). ذكّر المستخدمين بأخذ نسخة Excel احتياطية بشكل دوري — التطبيق يعرض تنبيهًا بهذا تلقائيًا.
